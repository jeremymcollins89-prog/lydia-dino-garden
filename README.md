# Lydia's Dino Garden

A calm puzzle and music game for Lydia's iPad.

**Live site:** https://jeremymcollins89-prog.github.io/lydia-dino-garden/

## Files in this repository

Both files sit at the top level of the repository (not inside a folder):

```
lydia-dino-garden/          <- the repository
├── index.html              <- the game
├── apple-touch-icon.png    <- iPad home screen icon (180×180)
└── README.md               <- this file
```

## Updating the game

1. Go to https://github.com/jeremymcollins89-prog/lydia-dino-garden
2. Click **Add file → Upload files**.
3. Drag in the new `index.html` (same name), then click **Commit changes**.
4. Wait 1–2 minutes, then close and reopen the app on the iPad.

## Changing the icon

1. Upload a new `apple-touch-icon.png` the same way.
2. On the iPad, remove the old home screen icon and add it again from Safari (Share → Add to Home Screen).

## Locking the iPad into the game

Settings → Accessibility → Guided Access → On. In the game, triple-click the top button to start; triple-click again and enter the passcode to exit.
